# JingXin 多模态面试评估系统 - 前端

## 📋 项目概述

JingXin是一个智能多模态面试评估系统的前端部分，通过同时分析面试者的面部表情、手势姿态、语音内容和眼动轨迹，提供全面、客观的面试评估报告。

### 核心价值
- **多模态融合分析**: 整合视觉、听觉、行为等多维度数据
- **实时评估反馈**: 毫秒级数据处理与即时结果展示
- **科研能力量化**: 五大维度精准评估（认知效率、沟通流畅度、自信水平、逻辑思维、压力韧性）
- **可视化报告**: 自动生成交互式HTML评估报告

### 应用场景
- 企业招聘面试
- 研究生入学评估
- 科研项目选拔
- 心理辅导与情绪管理培训

## 🛠️ 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Ant Design
- **状态管理**: Zustand
- **路由**: React Router DOM
- **可视化**: Plotly.js
- **HTTP客户端**: Axios
- **实时通信**: Socket.io-client
- **样式**: SCSS

## 🌐 API接口

前端与以下后端服务进行交互：
- Flask总控平台: http://localhost:5000
- 面部表情分析API: http://localhost:8000
- 手势姿态分析API: http://localhost:8001
- 语音交互API: http://localhost:8002

## 📊 主要功能模块

1. **首页**: 系统介绍与场景选择
2. **面试评估**: 实时视频采集与评估
3. **科研评估**: 针对科研场景的评估
4. **实时分析**: 多维度数据可视化
5. **报告页面**: 评估结果展示与下载

## ⚙️ 配置说明

开发服务器默认运行在 `http://localhost:5173`，API代理配置在 `vite.config.ts` 中设置。

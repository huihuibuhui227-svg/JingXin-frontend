## 3. 踩到的坑（**这部分是本文档最有价值的部分**）

每一条都是实测撞到的，不是推测。

### 3.1 `define: { global: 'globalThis' }` 会把 CSS 路径改坏

细粒度 plotly 需要浏览器里有个 `global`（见 3.2），网上通行做法是加
`define: { global: 'globalThis' }`。**但 Vite/esbuild 的 define 是字面文本替换**：

```
import './styles/global.css'   →   import './styles/globalThis.css'
```

构建直接报 `Could not resolve "./styles/globalThis.css"`。
**正解**：不改配置，改在入口加运行时 shim（`src/polyfills/global.ts`）。

### 3.2 细粒度 plotly 会静默全白

`plotly.js/lib/*` 的细粒度模块会拉进 `has-hover` / `has-passive-events` 等
CommonJS 依赖，它们引用 Node 的 `global`。浏览器里没这个符号 ⟹
`ReferenceError: global is not defined` ⟹ 四个图表组件全被 ErrorBoundary 兜成空白。
**构建不报错，是纯运行时的静默失败。**

### 3.3 shim 必须是「首位 import 的独立模块」

ESM 的 import 声明**会被提升**：模块体里的赋值语句无法抢在 import 之前执行。
把 `window.global = window` 写在 `main.tsx` 的 import 语句之前是**错的**（实际最后才跑）。
正解是做成独立模块 `src/polyfills/global.ts`，再把它排在 import 列表**第一个** ——
靠「import 按书写顺序求值」这条语义保证顺序。

### 3.4 没有任何预打包 dist 能覆盖本项目的 trace 组合

本项目用到 `bar` / `heatmap` / `scatter` / `scatterpolar` 四种，而：

- `plotly.js-basic-dist`：只有 scatter/bar/pie —— 缺 heatmap、缺 polar
- `plotly.js-cartesian-dist`：有 heatmap，但 **不含 polar**（polar 是独立模块）

⟹ 只能自建（`src/utils/plotlyBundle.ts`，`lib/core` + 四个模块 + `react-plotly.js/factory`）。

### 3.5 antd 预设彩色标签：组件 token 覆盖不到

`Tag` 的 `defaultBg` / `defaultColor` **只作用于默认标签**，管不到 `color="success"` /
`"processing"` 这类预设色 —— 它们的颜色是 antd 从 `colorPrimary` 派生出来的，实测不达 4.5:1
（录制素材页一次报 24 处）。

而且 antd 5 是 CSS-in-JS，生成的规则形如
`.ant-tag.css-dev-only-do-not-override-xxx.ant-tag-success`（**3 个类**），
普通写法的特异性不够会被压掉 —— 第一版覆盖就是这么失效的。必须 `.ant-tag.ant-tag-success`
加 `!important`。已写在 `global.css` 里并注明原因。

### 3.6 规范里的 `ink-muted-48` 不能当正文

规范把 `#7a7a7a` 用于「禁用态按钮文字与法务小字」，但它实测只有
**4.29:1**（白底）/ 3.94:1（米白底），**达不到 AA**。页脚法务行第一版用了它，立刻被 axe 报出。
按 `tokens.css` 里记的约定：**该档只留给禁用态**，真实文字用 `--ax-text-secondary`（米白底 4.66:1）。

### 3.7 重构中弄丢 `<main>`

首页重构成 `<section>` tile 时把外层 `<main>` 弄丢了（首页不用 antd 的
`Layout.Content`，而它自带 `<main>`），axe 立刻报 `landmark-one-main` + 10 处 `region`。
**每次重构页面结构都要重跑 a11y** —— 这类回归肉眼看不出来。

## 4. 遗留与待决

- **`scripts/a11y.mjs` 需要 `axe-core`**（`npm i -D axe-core`，已装）。它不依赖 webdriver，
  直接用 playwright 的浏览器，退出码可接 CI。
- **`ANALYZE=1 npm run build`** 才产出 `dist/stats.html`（默认不产出，避免每次构建多写一份）。
- **字体**：规范给的顺序是 SF Pro → system-ui → -apple-system，非 Apple 平台建议 Inter。
  本项目是中文界面且跑在 Linux 上，SF Pro 与 Inter 都不含汉字，所以后面显式接了中文字体链。
  **未引入 Web 字体**（内网工具不值得多一次网络往返）。若日后要更贴近规范，可自托管 Inter
  并把 display 字距再收紧 `-0.01em`。
- **`src/styles/variables.scss`** 已替换为废弃墓碑（原是死代码，`$primary-color: #2E86AB` 从未生效）。
- 未提交。本仓库约束：**禁止 `git add -A`**，一律显式列路径。
